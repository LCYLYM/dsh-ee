## 0. 准备

```bash

make build        # 或 .tools/scripts/rebuild.sh
```

- 准备三个账号：超级管理员、普通员工、只有部分管理权限的人（例如只有「额度分配」「用户」的角色）。

## 5. 品牌与外观（DSH 里）

> 2026-11-10 查清并修好：接入插件原来在**生成插件包时**按品牌开关写死要不要接管 logo，员工先装插件、管理员后开品牌，就一直是 DSH 的 logo；而且品牌注册排在远程服务和其它功能之后，任何一步卡住都换不掉。现在插件一启动就用 `priority: -1000` 占住品牌位置、按运行时的品牌开关接管或撤下，不再关掉官方品牌插件。本机 DSH 0.2.2-rc.1 的 `e2e/dsh/scenarios/run-brand.mjs`（先装插件、后开品牌、不更新插件）已通过。Mac Desktop 上请再看一眼。

| # | 怎么做 | 应该看到 |
|---|---|---|
| 5.1 | 品牌与外观：开启品牌，名称「星河科技」，首屏标题「星河科技企业工作台」，上传 logo，选「星河蓝」；然后在「DSH 接入插件」里发布 | 预览图实时跟着变 |
| 5.2 | 员工更新接入插件后打开 DSH | 侧栏左上是 logo + 星河科技；新会话首屏是 logo + 「星河科技企业工作台」，原来的标题和「预览版」角标不见了 |
| 5.3 | 同上 | 发送按钮、主按钮是蓝色；侧栏背景是浅灰蓝 |
| 5.4 | DSH 设置里切深色 | 发送按钮用深色那一份（浅蓝），侧栏回到 DSH 默认深色 |
| 5.5 | 不重启 DSH，在网页上改成「森林绿」、清空首屏标题 | 一分钟内（或切走再切回 DSH 窗口时）变成绿色，首屏恢复 DSH 自带标题 |
| 5.6 | logo 外形切「原样」「圆角方形」 | DSH 里 logo 不再被裁成圆形 |
| 5.7 | 关闭品牌 | 配色回到默认，品牌位置是中性的首字母图标 |
| 5.8 | DSH 里开管理模式，对 Agent 说「把主色换成 #c8102e，侧边栏用浅灰」 | 先出确认预览，列出 brand.theme.colors 的改动；同意后生效。说一个无效颜色（例如 url(...)）时，预览阶段就被拒绝 |
