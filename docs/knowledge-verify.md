> 2026-11-09。设计见 [knowledge-next.md](knowledge-next.md)。
> 网页部分已由 e2e `25-knowledge-docs`、`26-knowledge-ux` 在本机浏览器里跑通（截图在 `e2e/shots/kb2-*.png`、`kb4-*.png`）；**DSH 原文窗格和看板引用只有单元测试，没有在真实 DSH 里看过**，§6 需要在 Mac 上自测。

## 0. 准备

```bash
cd dsh-plugin && npm run build && cd ..   # 原文窗格、看板引用在插件里
make build                                 # 或 .tools/scripts/rebuild.sh
```

- 用**已有的库**启动一次（验证迁移 0021 `kb_docs.convert_info`、0022 `kb_gap_ignores`）。
- 准备真实文件：带自动编号的制度 Word（第一章 / 第一条）、有合并单元格的 Word 表格、多工作表的 Excel、GBK 编码的 CSV、带备注的 PPT、一份正常 PDF、一份扫描版 PDF、一份「抽出来是乱码」的中文 PDF（如果手上有）。
- 账号：一个知识库维护者、一个普通员工。

## 1. 上传与转换体检

| # | 怎么做 | 应该看到 |
|---|---|---|
| 1.1 | 知识库页点「上传文档」，一次选上面这些文件 | 每个文件一行，标「新文档」；按钮写「上传 N 个文件」 |
| 1.2 | 上传 | 每个文件一张体检卡：Word「补回 N 个条款编号 · N 个表格」；Excel「N 个工作表 · N 行」「第一行当作表头」；CSV「原文件是 GBK 编码，已转成 UTF-8」；PPT「收录 N 页幻灯片 · N 页带备注」；PDF「收录 N 页」，有扫描页时黄色「第 x 页是扫描页，没有收录…」 |
| 1.3 | 传一个 .doc / .xls / .ppt | 红字「旧版 Word（.doc）不支持，请在 Word 里另存为 .docx 后再上传」（xls、ppt 同理） |
| 1.4 | 传一份全是扫描页的 PDF | 红字「这份 PDF 是扫描件（没有文字层），暂不支持；有电子版的话请传电子版」 |
| 1.5 | 把同一个文件再传一次 | 这一行标「更新为第 2 版」，下面一行小字「这个目录里已经有…」；点「另存一篇」变回「新文档」 |
| 1.6 | 按默认（更新）上传 | 「已更新为第 2 版」；库里文档数不变；文档页版本列表有 v2，旧版本还能看、能恢复 |
| 1.7 | 把一个文件夹（含子文件夹）直接拖到文档列表上 | 上传窗口打开，文件带着各自的子目录；上传后目录树里出现对应目录 |
| 1.8 | 拖文件时 | 文档列表上出现「松开就上传到「…」」的蓝色虚线框 |

## 2. 阅读视图（网页文档页）

| # | 怎么做 | 应该看到 |
|---|---|---|
| 2.1 | 打开 Word 文档 | 标题、段落、表格正常排版（不是 Markdown 源码）；「第二章 …」「第三条 …」编号都在；纵向合并的单元格每行都有值 |
| 2.2 | 鼠标移到某一段的左边 | 显示这一行的行号 |
| 2.3 | 右上「原文（带行号）」 | 切回等宽字体 + 行号；再点「阅读」切回 |
| 2.4 | 打开 Excel 文档 | 顶部按工作表切换；每段上面一行浅色「第 2～42 行」，表头每段都有；数字列右对齐、隔行浅底色 |
| 2.5 | 打开 PPT | 每页一张卡片，标题加粗，备注浅色在卡片底部 |
| 2.6 | 打开 PDF | 每页之间一条分页线「第 N 页」；扫描页是灰色虚线框提示；每页重复的页眉页脚没有了 |
| 2.7 | 右侧「转换情况」 | 和上传时的体检卡一致；Markdown 文档没有这张卡 |
| 2.8 | Excel / CSV：右侧「表头」选「第一行就是数据」→「按这个设置重新转换」 | 生成新版本，表头变成 A、B、C；正文在网页上改过时先弹确认 |
| 2.9 | 长文档滚动 | 右侧大纲跟着高亮当前所在的标题；点大纲滚过去 |
| 2.10 | 5 万行的 Excel | 打开不卡；滚到底自动加载后面的段 |
| 2.11 | 切到暗色 | 文字、表格、高亮都看得清 |

## 3. 引用高亮

| # | 怎么做 | 应该看到 |
|---|---|---|
| 3.1 | 打开 `/knowledge/docs/<编号>?q=<一句原文>#L5-6` | 第 5～6 行左边一条蓝色竖线，那句话精确标黄，页面滚到中间 |
| 3.2 | q 写一句原文里没有的话 | 5～6 行整段浅色高亮（不标黄） |
| 3.3 | 摘句跨两行 | 两行各标一段（行尾的标点不标） |

## 4. 文档列表

| # | 怎么做 | 应该看到 |
|---|---|---|
| 4.1 | 有多级目录时 | 左边目录树，每个目录后面是文档数；点上级目录也显示子目录里的文档 |
| 4.2 | 切到「搜内容」输入一个正文里的词 | 只留下命中的文档，每篇下面一行命中的原文；点标题跳到那一行 |
| 4.3 | 勾选几篇 → 「移动到…」 | 输入目录后移动；目录树更新 |
| 4.4 | 勾选几篇 → 「删除」 | 先确认，再删除 |
| 4.5 | 列表 | 每篇前面是文件类型小方块（PDF 红、Word 蓝、Excel 绿、PPT 橙）；有页没收录的标「N 页未收录」；网页上改过正文的标「手工改过」 |

## 5. 检索情况、员工首页、编辑

| # | 怎么做 | 应该看到 |
|---|---|---|
| 5.1 | 在 DSH 里问一个知识库里没有的问题 | 维护者打开知识库 →「检索情况 · 待补 1」；最上面「没查到的」列出那个词、次数、人数 |
| 5.2 | 问一个要换说法才查到的问题 | 不出现在「没查到的」里 |
| 5.3 | 点「忽略」 | 这一条消失，以后也不再出现 |
| 5.4 | 「常被读的文档」 | 按最近 30 天被 AI 读的次数排 |
| 5.5 | 「检索流水」 | 默认收起，点开是原来的表格 |
| 5.6 | 知识库列表 | 维护的库卡片上有「待补 N」；每张卡片列最近更新的 3 篇，点了直接打开 |
| 5.7 | 普通员工打开「知识问答」页 | 顶部大搜索框；按 `/` 聚焦；搜出来按文档列出命中的行 |
| 5.8 | 输入问题点「在 DSH 里问」 | 提示「已复制…」；剪贴板里是 `/kb-qa 问题`；「打开 DSH」能把 DSH 调到前面 |
| 5.9 | 一个知识库都没有时（管理员） | 三步引导 + 「导入示例公司的制度」 |
| 5.10 | 有文档、但没有应用用它的库 | 库页顶部提示「这个库还没有应用在用」+「用这个库做问答应用」 |
| 5.11 | 文档页「编辑正文」 | 左边 Markdown、右边实时预览；下方黄色提示「新增 x 行、删去 y 行 · 这篇近 30 天被 AI 读过 N 次…」 |

## 6. DSH 里（需要真实 DSH，未验证）

| # | 怎么做 | 应该看到 |
|---|---|---|
| 6.1 | 「知识问答」里问一个问题，点看板上的引用 | 「原文」窗格是阅读视图（标题、表格排版），引用的段落左边竖线、摘句标黄，自动滚到那里 |
| 6.2 | 窗格里点「看原文（带行号）」 | 切成带行号的等宽原文；再点「阅读视图」切回 |
| 6.3 | 窗格宽度约 360～480 px 时看 Excel 表格 | 表格能横向滚动，不撑破窗格 |
| 6.4 | 看板上的引用 | 每条前面一个编号小圆标：绿色对得上、红色对不上、灰色原文已更新；鼠标移上去显示摘句 |
| 6.5 | 引用的是 PDF 里扫描页前后一页的内容 | 引用旁边黄字「⚠ 第 N 页没收录」 |
| 6.6 | 没有「原文」窗格的应用，点引用 | 打开网页，地址里带 `q=`，网页上那句话精确标黄 |
| 6.7 | AI 检索时（看工具调用） | 找某篇文档时结果里有 `docs`；查条款号用 `mode=regex`；长文档用 `kb__read` 的 `query` |
